# 🔐 Password Strength Checker

A simple Python-based **Password Strength Checker** that evaluates a password based on multiple security criteria.

The project checks whether a password is commonly used and analyzes its length, character types, and use of special characters to calculate a password strength score.

## 🚀 Features

- 🔎 Checks whether the password is a commonly used password
- 📏 Checks password length
- 🔠 Checks for uppercase letters
- 🔡 Checks for lowercase letters
- 🔢 Checks for numbers
- 🔣 Checks for special characters
- 📊 Calculates a password strength score
- 🖥️ Includes a graphical user interface (GUI)
- 🧩 Uses separate Python modules for better code organization

## 🛠️ Technologies Used

- **Python**
- **Tkinter** — GUI development
- **Regular Expressions (`re`)** — character pattern checking
- **Git & GitHub** — version control and project hosting
